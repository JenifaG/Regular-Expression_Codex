THE BIG PICTURE

From grammar to pattern

Tap a tile to explore

A regular expression is a compact way to describe a set of strings. It sits beside grammars in the language-theory toolbox: useful for repeated shapes, while nested structure needs a more powerful grammar.

⌘

Where do CFGs fit?

Regular expressions describe regular languages. Context-free grammars (CFGs) can describe nested structures such as balanced parentheses. Python's re module is great for text patterns, but a parser/CFG is the right tool when nesting matters.
